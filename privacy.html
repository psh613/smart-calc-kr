개인정보처리방침

스마트계산기(이하 "사이트")는 이용자의 개인정보를 소중히 다루며, 필요한 최소한의 범위에서만 처리합니다.

1. 수집하는 개인정보

사이트는 회원가입, 로그인, 결제 기능이 없으며 이름·전화번호·주민등록번호·이메일 등 개인을 식별할 수 있는 정보를 수집하지 않습니다.

계산기에 입력하는 연봉, 보유 수량, 투자 금액 등은 이용자의 브라우저 안에서만 계산에 사용되며, 서버로 전송되거나 저장되지 않습니다.

2. 브라우저 저장소(localStorage) 사용

코인 계산기의 환율(1달러 = ? 원)처럼 다시 방문했을 때 유지하면 편한 값은 이용자 기기의 브라우저 저장소에만 저장됩니다. 이 값은 서버로 전송되지 않고, 브라우저 설정에서 언제든 삭제할 수 있습니다.

3. 호스팅과 서버 접속 기록

사이트는 GitHub Pages로 제공됩니다. 페이지를 불러오는 과정에서 호스팅 사업자인 GitHub가 접속 IP, 브라우저 정보, 접속 시각 등의 기록을 남길 수 있습니다. 이는 사이트 운영자가 직접 수집·보관하는 정보가 아니며, GitHub의 개인정보처리방침이 적용됩니다.

4. 쿠키 및 광고

현재 사이트는 자체적으로 쿠키를 사용하지 않으며, 방문자 분석 도구나 광고 스크립트를 넣지 않았습니다.

향후 사이트 운영 비용 충당을 위해 Google AdSense 등 제3자 광고를 도입할 수 있습니다. 광고가 도입되면 제3자 광고 사업자가 쿠키를 사용해 이용자의 관심 기반 광고를 게재할 수 있고, 이용자는 Google의 광고 설정에서 맞춤 광고를 해제할 수 있습니다. 도입 시점에 이 방침을 먼저 개정해 고지합니다.

5. 외부 링크

사이트는 GitHub 저장소 등 외부 사이트로 연결되는 링크를 포함할 수 있습니다. 외부 사이트의 개인정보 처리에 대해서는 해당 사이트의 방침이 적용됩니다.

6. 아동의 개인정보

사이트는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 이용자의 권리

사이트가 이용자의 개인정보를 보관하지 않으므로 열람·정정·삭제를 요청할 대상 정보가 없습니다. 브라우저에 저장된 환율 값은 브라우저 설정의 사이트 데이터 삭제 기능으로 직접 지울 수 있습니다.

8. 문의

개인정보 처리와 관련한 문의나 오류 제보는 GitHub 저장소의 이슈로 남겨 주세요. 확인 후 안내드리겠습니다.

9. 방침의 변경
